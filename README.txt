اسکنر سرور مستراستریم — راهنمای اجرا
========================================

اجرا:
  1) pip install PySide6
  2) python masterstream_scanner.py

اولین قدم مهم:
  آدرس دقیق سرورها (هاست RTMP) عمومی نیست و فقط داخل «پنل کاربری
  مستراستریم» نمایش داده می‌شود. یک‌بار از پنل، آدرس RTMP هر سرور را کپی
  کنید و با دکمه «ویرایش» (یا «درون‌ریزی گروهی» برای همه یکجا) وارد برنامه کنید.
  قالب درون‌ریزی گروهی، هر خط یک سرور:
      نام سرور | rtmp://host:1935/live

نحوه کار اسکن:
  برنامه با اینترنت خود شما به هر سرور پینگ می‌زند و زمان برقراری اتصال
  TCP به پورت RTMP (پیش‌فرض 1935) را چند بار اندازه می‌گیرد، بعد سرورها را
  امتیازدهی و مرتب می‌کند و بهترین سرور «ایران» را برای استریم روی Kick
  پیشنهاد می‌دهد.

نکته‌ها:
  - فقط سرورهای «ایران» برای اتصال شما مناسب‌اند.
  - اطلاعات در فایل servers.json کنار برنامه ذخیره می‌شود.
  - برای ساخت نسخه exe (بدون نیاز به نصب پایتون): PyInstaller
