# StreamScanner — نسخه اندروید

نسخه اندروید برنامه StreamScanner با فریم‌ورک Kivy؛ دقیقاً همان قابلیت‌های نسخه ویندوز:

- تست موازی همه سرورها (TCP به پورت RTMP؛ روی اندروید پینگ ICMP معمولاً بدون روت کار نمی‌کند، پس امتیازدهی TCP-محور است و پینگِ جواب‌نداده نادیده گرفته می‌شود)
- تشخیص خودکار نام و منطقه از روی لینک RTMP
- رتبه‌بندی و بنر بهترین سرور + دکمه کپی آدرس RTMP
- افزودن / ویرایش / حذف سرور، درون‌ریزی گروهی
- ۸ تم + تم سیستمی با اعمال لحظه‌ای (پیش‌نمایش زنده در تنظیمات)
- دوزبانه کامل فارسی (راست‌به‌چپ) / انگلیسی
- تک‌لمس: انتخاب ردیف — دابل‌تاپ روی ردیف: کپی آدرس RTMP در کلیپ‌بورد
- تنظیمات: تم، زبان، بررسی خودکار آپدیت
- آپدیت درون‌برنامه‌ای: فقط ریلیزهای `android-v*` گیت‌هاب بررسی می‌شوند؛ APK دانلود و نصب پیشنهاد می‌شود (PackageInstaller، بدون نیاز به FileProvider)

## ساختار

| فایل | توضیح |
|---|---|
| `main.py` | رابط Kivy (۵ صفحه: اصلی، فرم سرور، درون‌ریزی، تنظیمات، آپدیت) |
| `core.py` | منطق خالص بدون وابستگی UI (بازاستفاده از نسخه ویندوز) |
| `buildozer.spec` | مشخصات بیلد اندروید |
| `assets/icon.png` | آیکون برنامه |
| `assets/fonts/Vazirmatn-Regular.ttf` | فونت فارسی |

## بیلد و انتشار

بیلد با GitHub Actions انجام می‌شود (`.github/workflows/android.yml`) و فقط روی تگ‌های `android-v*` اجرا می‌شود تا با ورک‌فلوی ویندوز قاطی نشود:

```bash
git tag android-v1.0.2
git push origin android-v1.0.2
```

ورک‌فلو نسخه را از روی تگ استخراج می‌کند (`buildozer.spec` و `core.py` را به‌روز می‌کند)، APK را با Buildozer می‌سازد و یک Release عمومی با فایل `StreamScanner-Android.apk` می‌سازد.

نکته امضای تکراری: کلید دیباگ (`~/.android/debug.keystore`) در کش Actions نگه داشته می‌شود تا همه بیلدها یک امضا داشته باشند و آپدیت درون‌برنامه‌ای بدون حذف/نصب مجدد کار کند.

## محدودیت‌های شناخته‌شده

- متن فارسی تایپ‌شده داخل فیلدهای ورودی در Kivy شکل‌دهی نمی‌شود (حروف جدا نمایش داده می‌شوند)؛ متن‌های نمایشی برنامه کاملاً شکل‌یافته‌اند.
- ایموجی‌ها در دکمه‌ها/برچسب‌ها حذف شده‌اند چون فونت ایموجی ندارد.
